## ADDED Requirements

### Requirement: 定投自动化区块应提供统一的区块身份与摘要
`SIPPlanManager` MUST 在计划列表前提供清晰的区块身份、说明文案与摘要卡，而不只是标题和按钮。

#### Scenario: 用户进入定投自动化区块
- **GIVEN** 用户查看交易页中的定投自动化区块
- **WHEN** 页面完成渲染
- **THEN** 页面应展示区块标题、说明文案与执行中 / 已暂停 / 已排期摘要

### Requirement: 定投自动化状态反馈应复用统一状态语言
`SIPPlanManager` MUST 在未登录、加载、空态与错误态下复用统一状态组件，而不是继续使用零散占位块。

#### Scenario: 用户遇到状态反馈
- **GIVEN** 定投自动化区块处于未登录、加载、空态或错误态
- **WHEN** 页面渲染对应状态
- **THEN** 页面应展示统一的标题、说明和可选动作

### Requirement: 定投自动化视觉升级后应保持原有交互
`SIPPlanManager` 视觉升级后 MUST 保持创建、编辑、启停、删除与标记执行等既有交互可用。

#### Scenario: 用户继续管理定投计划
- **GIVEN** 定投自动化区块已升级
- **WHEN** 用户继续创建或调整计划
- **THEN** 原有交互逻辑和前端回归测试应继续通过
