## 为什么

交易工作台视觉升级 phase8 完成后，`TradeCenter` 主体已经进入统一语言，但嵌在中段的 `SIPPlanManager` 仍是另一套老式工具型样式：白卡 + utility class + 零散按钮，和当前交易工作台的克制、高级、低噪声基调存在明显断层。

当前最直接的问题有三类：

1. `SIPPlanManager` 缺少页面身份与摘要层，用户只能看到“定投计划”标题和按钮，无法快速理解当前自动化状态。
2. 计划卡、表单和动作按钮仍停留在旧式浅色块堆叠，缺少更一致的层级、留白与主次关系。
3. 登录态、加载态、空态和错误态没有复用已有 `SurfaceState` 语言，和交易页其他区块不一致。

## 变更内容

1. 建立 `frontend-design-refresh-phase9` 变更入口。
2. 聚焦 `SIPPlanManager` 的头部、摘要卡、计划表单、计划卡和状态面语言，不改 API 与业务行为。
3. 新增 `SIPPlanManager` 独立最小回归，并继续执行全量前端测试、analyze 与发布预检。

## 影响

- 让交易页内的定投自动化区块与 `TradeCenter` 主体进入同一套视觉体系。
- 将 `SurfaceState` 扩展到定投自动化的登录、加载、空态与错误反馈。
- 不改变定投计划的创建、编辑、启停、删除与执行行为。
