## 设计目标

本轮继续参考 Apple HIG 的清晰层级、Google Material 3 的摘要卡组织、GitHub Primer 的 page layout / detail view 经验，以及 OpenAI 官网克制的区块式表达，对 `FundDetailPage` 的二级信息区做三件事：

1. **净值走势先给性能快照**：在图表前先展示最新单位净值、估算偏差和当前可见区间。
2. **交易记录先给执行快照**：在表格前先展示总记录、已确认和待确认数量。
3. **让二级卡片与详情页 hero 连起来**：标题、说明和摘要卡采用同一套语言，减少“标题一行 + 内容一坨”的割裂感。

## 设计原则

### 1. 先摘要再下钻
- 用户进入走势和交易区时，先看到最重要的当前状态。
- 图表和表格保留，但不再是第一眼唯一内容。

### 2. 控制信息密度
- 摘要卡只容纳一类核心信号和一句说明。
- 避免把原有表格或图表逻辑复杂化。

### 3. 行为保持不变
- 时间区间按钮、表格分页、返回按钮与数据加载流程都不变。
- 本轮仅收视觉层级与信息结构。

## 非目标

- 本轮不改右侧 `持仓详情` 与 `最新净值` 计算逻辑。
- 本轮不新增图表类型或交易筛选器。
- 本轮不改基金详情 API。
