## 为什么

`FundDetailPage` 的首页级 hero 与概览卡已经完成收口，但二级内容区里 `净值走势` 与 `交易记录` 仍主要依赖普通卡片标题 + 内容本体的旧结构：信息可用，但缺少“先摘要、再下钻”的节奏，和当前首页、设置中心、风险中枢的工作台语言还有一段距离。

当前最直接的问题有三类：

1. `净值走势` 区块直接进入图表与时间切换，缺少“当前净值 / 估算偏差 / 可见区间”的摘要层。
2. `交易记录` 区块直接进入表格，`total / confirmed / pending` 三类状态没有被提升为一眼可读的执行快照。
3. 两块内容虽然功能齐全，但仍偏传统数据卡片，尚未形成像 Apple / Google / OpenAI 官网那种克制、连续的分层表达。

## 变更内容

1. 建立 `frontend-design-refresh-phase17` 变更入口。
2. 聚焦 `FundDetailPage` 的 `净值走势` 与 `交易记录` 两块，补齐摘要头部与二级快照卡。
3. 保持图表、筛选按钮、交易表格和返回行为不变，并补最小视觉锚点测试。

## 影响

- 让基金详情页二级区块也遵循“摘要先行”的统一工作台语言。
- 保持 `FundDetailPage` 数据加载、时间区间切换与表格行为不变。
- 不调整详情页 API 或业务计算逻辑。
