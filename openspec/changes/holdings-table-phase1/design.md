## 上下文

当前 `HoldingsTable.jsx` 已经支持：

- 列显示/隐藏偏好持久化；
- 简洁/详细模式切换；
- 大列表编辑与保存。

但对零份额持仓的处理仅停留在“显示为 `--`”，尚未提供真正的隐藏能力，也未形成完整关单证据。

## 目标 / 非目标

**目标：**
1. 保留现有列自定义能力；
2. 新增零份额持仓隐藏能力；
3. 通过现有测试文件补足最小回归。

**非目标：**
1. 本轮不重做持仓页布局；
2. 本轮不调整后端持仓接口；
3. 本轮不改变默认排序逻辑。

## 决策

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 零份额处理 | 前端表格层直接隐藏 | 改动面最小，不影响后端数据源 |
| 验证方式 | 扩展 `HoldingsTable.test.jsx` | 现有回归文件最贴近该能力 |
| 状态同步 | 回写 `ROADMAP.md` 与 `docs/最新进度.md` | 保持路线图与实现一致 |

## 验证策略

1. `npm --prefix frontend run test:run -- src/components/HoldingsTable.test.jsx`
2. 确认 `ROADMAP.md` 中该项转为已完成
