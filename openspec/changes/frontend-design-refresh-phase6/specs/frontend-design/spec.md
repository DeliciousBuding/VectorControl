## ADDED Requirements

### Requirement: 高优先级页面应使用统一状态语言
高优先级页面 MUST 使用统一的状态组件来表达 loading / error / empty 等反馈，而不是仅用散落的占位文本。

#### Scenario: 页面数据尚未就绪
- **GIVEN** 页面正在加载或数据为空
- **WHEN** 状态面渲染
- **THEN** 页面应展示统一的图标、标题、描述和提示文案

### Requirement: 状态反馈应保持克制且可操作
状态组件 MUST 提供简洁的反馈层级，并保留页面原有的交互动作与恢复路径。

#### Scenario: 页面出现错误
- **GIVEN** 页面请求失败
- **WHEN** 错误状态渲染
- **THEN** 页面应展示简洁错误标题和说明
- **AND** 页面原有的返回、刷新或后续操作路径仍应保留

### Requirement: 统一状态语言不应改变原有业务行为
引入统一状态组件后 MUST 保持页面原有的数据加载、测试与导航行为不变。

#### Scenario: 页面继续执行原交互
- **GIVEN** 页面已经升级到统一状态语言
- **WHEN** 用户继续执行原有交互
- **THEN** 现有行为和回归测试应继续通过
