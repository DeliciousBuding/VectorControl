## ADDED Requirements

### Requirement: 基金详情页应提供页面身份与摘要层
基金详情页 MUST 在详细图表和数据卡之前提供清晰的页面身份与摘要层，帮助用户快速理解当前基金和关键状态。

#### Scenario: 用户进入基金详情页
- **GIVEN** 用户打开某只基金的详情页
- **WHEN** 页面渲染完成
- **THEN** 页面应展示返回入口、基金名称、代码与状态标签
- **AND** 页面应展示市值、持有收益、当日涨跌等关键摘要信息

### Requirement: 基金详情页应保持双栏详情节奏
基金详情页 MUST 将图表 / 交易记录与持仓 / 状态 / 最新净值分成职责清晰的左右内容区。

#### Scenario: 用户浏览详情页主体
- **GIVEN** 基金详情数据已返回
- **WHEN** 页面渲染主内容区
- **THEN** 左侧应展示净值走势和交易记录
- **AND** 右侧应展示持仓详情、数据状态与最新净值信息

### Requirement: 详情页视觉升级后应保持现有交互可用
基金详情页视觉升级后 MUST 保持返回、区间切换和交易记录展示等既有行为可用。

#### Scenario: 用户继续操作详情页
- **GIVEN** 详情页视觉已升级
- **WHEN** 用户执行返回或切换走势图区间
- **THEN** 现有行为和回归测试应继续通过
