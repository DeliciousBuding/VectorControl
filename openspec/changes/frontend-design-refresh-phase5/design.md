## 设计目标

本轮在前四个 phase 之后继续做两件事：

1. **让基金详情页具备 PageHeader 和详情页身份**：参考 Ant Design Workbench 对“降低记忆负载、缩短获取关键信息路径”的要求，以及 Primer 的 split page layout 原则，让用户进入详情页后先理解“我正在看哪只基金、当前状态如何、最重要的数字是什么”。
2. **让左右双栏真正承担“内容区 + 元信息区”职责**：参考 Primer 对 list-detail / split layout 的窄屏退化和侧栏信息组织方式，以及 Saleor Dashboard 的后台详情卡片层级，把图表 / 交易记录与持仓 / 状态 / 最新净值收进统一节奏。

## 设计原则

### 1. 头部先给页面身份
- 返回、页面标识、基金名称、代码、市场标签、数据状态要在头部形成稳定的上下文。
- 头部应承担“进入详情页后的第一眼判断”，而不是只做标题占位。

### 2. 摘要卡先于明细
- 市值、持有收益、当日涨跌等关键指标应先进入概览区。
- 摘要卡需要保留正负语义，并与右侧详细指标保持一致的颜色和文案口径。

### 3. 双栏保持信息职责清晰
- 左侧以趋势和最近交易为主。
- 右侧以持仓、状态和最新净值为主。
- 窄屏下允许退化为单列，但不改变信息优先级。

## 非目标

- 本轮不更改基金详情数据接口。
- 本轮不改图表算法或交易表格字段。
- 本轮不引入新的复杂图表或动画。
