## ADDED Requirements

### Requirement: 导航配置应在桌面与移动端共享
首页导航 MUST 由共享配置驱动，确保桌面侧边栏与移动端底部标签栏的标签、图标和分组语义保持一致。

#### Scenario: 首页导航渲染
- **GIVEN** 用户进入应用主工作台
- **WHEN** `SideNav` 与 `BottomTabs` 渲染
- **THEN** 两者应使用同一份导航配置生成导航项
- **AND** 导航项应包含标签、图标与说明语义

### Requirement: 侧边导航应提供当前工作区与分组层级
桌面侧边导航 MUST 提供当前工作区概览、分组标签与激活项高亮，帮助用户快速理解当前位置和可用入口。

#### Scenario: 用户查看桌面侧边栏
- **GIVEN** 桌面端渲染 `SideNav`
- **WHEN** 当前激活页为任意主 tab
- **THEN** 侧边栏应展示“当前工作区”概览
- **AND** 导航应按“工作台 / 账户”等分组展示
- **AND** 当前激活项应具有更高视觉优先级和 `aria-current` 语义

### Requirement: 移动端导航应延续桌面语义
移动端导航 MUST 在底部标签栏与抽屉中延续桌面导航的命名、说明和当前项语义。

#### Scenario: 用户在移动端切换导航
- **GIVEN** 移动端渲染 `BottomTabs` 与抽屉导航
- **WHEN** 用户查看或切换导航项
- **THEN** 底部标签栏应展示共享导航标签与图标
- **AND** 抽屉应保留分组结构与当前项语义
