## 为什么

首页 phase1 与 phase2 已分别收敛概览区、工具栏和基准区，但左右导航仍保留旧风格：侧边栏与底部标签栏来自两套独立配置，信息层级偏薄，当前工作区缺少明确提示，移动端入口也没有完整承接“工作台导航”的角色。

当前直接问题有三类：

1. `SideNav` 与 `BottomTabs` 使用各自维护的导航定义，容易出现标签、图标与分组口径漂移。
2. 侧边导航只有“列表点击”语义，没有“当前工作区 / 分组导航 / 移动端入口”的工作台结构。
3. 底部标签栏虽然承担移动入口，但与桌面侧边栏缺少统一视觉语言和可访问性语义。

## 变更内容

1. 建立导航体系视觉升级 phase3 的 OpenSpec 入口。
2. 聚焦 `SideNav`、`BottomTabs` 与共享导航配置的统一，形成桌面 / 移动一致的工作台导航语言。
3. 要求补齐导航最小回归，并继续执行 `test:run`、`analyze` 与发布预检。

## 影响

- 首页与主导航更像一套完整的投资工作台，而不是零散入口集合。
- 桌面与移动端共享导航配置，后续继续升级详情页或设置页时可复用同一套导航语义。
- 不改后端接口，不扩大业务计算回归面。
