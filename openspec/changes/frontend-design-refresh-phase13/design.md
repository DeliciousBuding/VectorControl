## 设计目标

本轮继续参考 Apple HIG 的层级克制、Google Material 3 的摘要先行、GitHub Primer 的 page layout / 信息分组方式，以及 OpenAI 官网简洁的区块化表达，对 `RiskStatusBar` 做三件事：

1. **先说明这是什么**：用 `Risk Snapshot` 明确其是进入风险中枢前的首页快照。
2. **先给三类风险摘要**：集中度、回撤预估、结构预警并列展示，便于首屏扫读。
3. **让 CTA 退居其后**：先读状态，再进入详情，不再把按钮和状态块混成同一层。

## 设计原则

### 1. 风险入口先摘要后跳转
- 入口条先给风险快照身份和简短解释。
- 用户读完三类摘要后，再决定是否进入 `RiskCenter`。

### 2. 与风险中枢共用同一套语言
- 保持 `Risk Snapshot` / 快照卡 / chip 语义一致。
- 让首页和详情页之间形成自然过渡。

### 3. 空态也保持产品化表达
- 无风险数据时仍保留快照区结构。
- 空态只提示“刷新后可见什么”，不堆砌操作说明。

## 非目标

- 本轮不改 `RiskCenter` 的指标与风险计算逻辑。
- 本轮不扩展新的风险字段或 CTA 行为。
- 本轮不重构首页其他面板。
