## 设计目标

本轮首页视觉升级遵循两条约束：

1. **工作台视角**：首屏先给“概览 + 状态 + 最近趋势”，让用户先完成判断，再进入交易或排障。
2. **最小回归面**：优先动首页叶子组件与样式，不碰数据流与接口。

## 设计原则

### 1. 概览优先
- 将首页顶部收敛为统一的 `home-overview` 容器。
- 把“最近同步 / 已纳入持仓”与主指标放在同一视觉块中。

### 2. 状态结构化
- `DataStatusBanner` 改为“标题 + 状态 + 时点 + 说明”三段式结构。
- 让状态信息从一行文本变成可扫描的信息块。

### 3. 收益面板更像监控而非普通卡片
- `PortfolioReturnsPanel` 补充 `section-kicker` 与最新时点卡片。
- 摘要信息、主图表、近 7 天列表之间维持稳定节奏。

### 4. 主题与首页样式收敛
- Ant Design `theme.token` 与首页自定义样式统一主色、圆角与字体方向。
- 同步补齐暗色模式下的新容器与卡片背景。

## 非目标

- 本轮不重构 `TopToolbar`、`SideNav` 与设置中心整体视觉。
- 本轮不引入新的 UI 框架或远程字体依赖。
- 本轮不调整任何接口或业务逻辑。
