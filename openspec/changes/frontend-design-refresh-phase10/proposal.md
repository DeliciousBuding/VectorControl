## 为什么

首页、交易工作台和定投自动化区块已经逐步进入统一语言后，`HoldingsTable` 成为下一处最值得收口的高频核心页面。它承担用户日常查看持仓、收益、空仓过滤与快速操作的主路径，但头部与工具栏仍偏“配置面板 + 表格”组合，缺少更明确的产品级摘要与操作节奏。

当前最直接的问题有三类：

1. 表格头部只有标题与说明，没有把“当前行数 / 持仓总额 / 视图模式”等摘要前置。
2. 工具按钮仍是散装排列，缺少对表格操作与数据筛选的更清晰分组。
3. 表格 hover 样式定义存在，但行级 class 没有稳定挂到所有行，导致交互反馈不完全一致。

## 变更内容

1. 建立 `frontend-design-refresh-phase10` 变更入口。
2. 聚焦 `HoldingsTable` 的头部、概览条、工具栏与表格外壳，不改列逻辑与编辑行为。
3. 补最小回归，并继续执行全量前端测试、analyze 与发布预检。

## 影响

- 让持仓表从“配置 + 表格”收敛为更完整的产品级高密度工作区。
- 提升表格 hover / 选中 / 编辑态的一致性与可见性。
- 不改变持仓编辑、排序、审计和自动补全等既有行为。
