## 设计目标

本轮继续参考 Apple HIG 的信息层级、Google Material 的数据密集视图、GitHub Primer 的 page layout / table 组织方式，以及 OpenAI 官网的低噪声产品语言，对 `HoldingsTable` 做三件事：

1. **让表格先给摘要再给明细**：用户先看到当前行数、持仓总额与视图模式。
2. **让工具栏变成操作层而不是散装按钮**：空仓过滤、简洁模式与列设置进入同一组工具条。
3. **让表格壳与行反馈更一致**：表格外壳、hover、选中与编辑态语言统一。

## 设计原则

### 1. 表格也是页面，不只是容器
- 标题、说明、概览卡和工具栏形成独立的阅读顺序。
- 明细表格退居第二层。

### 2. 摘要与操作分层
- 概览区负责解释当前视图。
- 工具栏负责当前操作。

### 3. 保持行为不变，只收敛表面
- 不改列定义逻辑。
- 不改排序、编辑、审计、自动补全入口。

## 非目标

- 本轮不重构 `HoldingsTable` 的列配置逻辑。
- 本轮不扩展到详情弹层或批量操作。
- 本轮不改后端数据结构或接口。
