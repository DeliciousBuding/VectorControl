## 新增需求

### 需求: 基金详情必须支持独立页面路由
系统必须允许从持仓或基金中心进入独立的基金详情页面，而不是只能在原页面内滚动查看。

#### 场景: 用户打开单只基金详情
- **当** 用户触发基金详情导航
- **那么** 路由进入 `/fund/:fund_id`
- **并且** 页面显示对应基金的独立详情视图

### 需求: 基金详情页必须以高信息密度展示核心信息
基金详情页必须以紧凑布局展示图表、交易记录与持仓详情，避免信息过于分散。

#### 场景: 用户查看基金详情页
- **当** 页面成功加载基金详情
- **那么** 页面左侧展示净值走势与交易记录
- **并且** 页面右侧展示持仓详情与最新净值摘要
