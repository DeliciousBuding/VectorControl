## 设计目标

本轮在 phase1 之上继续做两件事：

1. **让顶部工具栏承担上下文职责**：参考 Ant Design `PageHeader` 与 Workbench，把标题、快照、搜索、状态、操作分成明确层级。
2. **让基准对比先有概览再有明细**：参考后台类开源 dashboard 的“overview -> cards”节奏，先给总览指标，再给单项基准卡。

## 设计原则

### 1. 顶部头部不只是按钮容器
- `TopToolbar` 需要具备 PageHeader 的页面身份与快照摘要能力。
- 把“数据时点 / 覆盖率 / 刷新状态”上提为头部快照卡。

### 2. 弹层信息前置一部分
- 保留原状态弹层做深层诊断。
- 但把结算状态、最近刷新、计算模式、口径说明压成上下文条，减少用户来回点开弹层。

### 3. 基准区先总览后下钻
- 在 `BenchmarkComparisonPanel` 顶部增加 overview 卡片。
- 单 benchmark 卡保留原数值，但增强标题层级与语义标签。

## 非目标

- 本轮不重构侧边导航和底部标签栏的导航逻辑。
- 本轮不引入新的图表或复杂动效。
- 本轮不改任何业务数据计算逻辑。
