## 为什么

phase17 已收口 `FundDetailPage` 左侧的 `净值走势` 与 `交易记录`，但右侧 `持仓详情` 与 `最新净值` 仍保留相对传统的“标题 + 指标网格 / 双栏对照”表达：结构清楚，但还没有完全进入当前项目的摘要式详情语言。

当前最直接的问题有三类：

1. `持仓详情` 缺少位于明细指标前的“份额 / 成本 / 当日收益”摘要层。
2. `最新净值` 区块虽然有双栏对照，但没有一个统一的“当前估值快照”身份和摘要卡层。
3. 右栏和刚完成的左栏在层级语言上仍有轻微割裂，尚未形成完整的一页式详情工作台体验。

## 变更内容

1. 建立 `frontend-design-refresh-phase18` 变更入口。
2. 聚焦 `FundDetailPage` 的 `持仓详情` 与 `最新净值` 两块，补齐摘要头部与右栏快照卡。
3. 保持原有详情指标、净值对照和返回行为不变，并补最小视觉回归锚点。

## 影响

- 让基金详情页左右两栏统一进入同一套“摘要先行”的设计语言。
- 保持基金详情原有数据逻辑和交互稳定。
- 不修改基金详情 API 或指标计算逻辑。
