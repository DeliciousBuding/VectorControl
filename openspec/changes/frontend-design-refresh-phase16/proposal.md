## 为什么

`LoginPanel` 目前仍主要依赖行内样式和标准 `Card + Form` 结构，虽然功能完整，但和已经完成收口的首页、设置中心与风险入口相比，认证入口仍明显偏“工具表单”而不是“产品入口”。

当前最直接的问题有三类：

1. 认证入口缺少上下文说明和摘要信息，用户一进入就只看到表单。
2. 登录 / 注册模式切换与认证表单层级较平，缺少更清晰的入口身份与工作区说明。
3. 组件样式依赖行内样式，不利于继续沿用统一的 design token 和响应式语言。

## 变更内容

1. 建立 `frontend-design-refresh-phase16` 变更入口。
2. 聚焦 `LoginPanel`，补齐工作区入口头部、摘要卡和模式切换容器，并去掉关键行内样式。
3. 新增最小测试，覆盖默认登录态展示与注册态提交契约。

## 影响

- 让认证入口也具备当前产品的统一视觉语言。
- 保持登录 / 注册行为、表单字段和 `onSubmit` 契约不变。
- 为后续继续收认证错误、空态和会话体验提供统一外壳。
