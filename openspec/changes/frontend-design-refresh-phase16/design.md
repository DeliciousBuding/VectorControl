## 设计目标

本轮继续参考 Apple HIG 的入口页克制层级、Google Material 3 的认证表单组织、GitHub Primer 的 sign-in / form control 节奏，以及 OpenAI 官网简洁的工作区入口表达，对 `LoginPanel` 做三件事：

1. **先说明这是工作区入口**：让用户先理解登录 / 注册会带来什么，而不是直接面对两个输入框。
2. **先给摘要，再给表单**：通过三张概览卡传达独立工作区、自动恢复和会话安全。
3. **把模式切换纳入统一容器**：让登录 / 注册模式切换成为清晰的分段控制，而不是普通按钮并排。

## 设计原则

### 1. 认证入口也要有产品身份
- 标题与摘要说明先于表单字段出现。
- 登录页仍然克制，但不再只是默认表单。

### 2. 风格统一
- 使用当前项目已经落地的圆角、轻边框、柔和渐变与摘要卡语言。
- 减少行内样式，统一进入样式层。

### 3. 行为保持不变
- 不修改 `onSubmit` 参数结构。
- 不改变登录 / 注册校验与 message 提示逻辑。

## 非目标

- 本轮不修改认证 API。
- 本轮不引入第三方登录或找回密码流程。
- 本轮不调整登录成功后的导航逻辑。
