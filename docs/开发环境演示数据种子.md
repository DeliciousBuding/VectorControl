# 开发环境演示数据种子（dev_seed_demo）

更新时间：2026-02-10 15:24:50

用途：为本地 dev 数据库写入最小演示数据，便于前端验收和回归测试。

## 1. 安全约束

- **仅限本地 dev 数据库**：禁止在生产环境执行
- **不含真实凭据**：所有数据均为演示用途
- **二次确认**：默认需要手动输入 `YES` 确认

## 2. 使用方法

### 2.1 预览（dry run）

```bash
python scripts/dev_seed_demo.py --db ./dev.db --dry-run
```

### 2.2 执行写入

```bash
# 需要二次确认
python scripts/dev_seed_demo.py --db ./dev.db

# 跳过确认（危险，仅在 CI 或自动化场景使用）
python scripts/dev_seed_demo.py --db ./dev.db --confirm
```

## 4. 验收检查

写入成功后，可通过以下方式验证：

```bash
# 检查用户
sqlite3 dev.db "SELECT * FROM users WHERE id=1"

# 检查持仓
sqlite3 dev.db "SELECT * FROM holdings WHERE user_id=1"

# 检查交易
sqlite3 dev.db "SELECT * FROM fund_transactions WHERE user_id=1 LIMIT 5"
```

## 5. 回滚

如需清空演示数据：

```bash
sqlite3 dev.db "DELETE FROM users WHERE username='demo_user'"
sqlite3 dev.db "DELETE FROM holdings WHERE user_id=1"
sqlite3 dev.db "DELETE FROM fund_transactions WHERE user_id=1"
sqlite3 dev.db "DELETE FROM sip_plans WHERE user_id=1"
```

## 6. 注意事项

- 执行前确保数据库已备份（如有重要数据）
- 演示基金代码为真实存在但不含敏感信息
- 交易日期为相对于当前日期的前 30 天内
