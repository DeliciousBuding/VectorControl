# VectorControl 更新日志

## 2026-02-09 - mot-bot 开发马拉松

### 新增功能

#### 1. 收益曲线图 📊
- **位置**：首页 SummaryCards 下方
- **功能**：
  - 支持 7天/30天/90天/全部 四个时间范围切换
  - 显示累计收益率曲线
  - 0% 基准线
- **技术**：Chart.js + react-chartjs-2
- **API**：`/api/charts/cumulative_returns`

#### 2. 基准对比 📈
- **位置**：首页收益曲线下方
- **功能**：
  - 对比沪深300、中证500、创业板50
  - 显示超额收益
  - 标记跑赢/跑输状态
  - 高亮最接近的基准
- **API**：`/api/benchmark/comparison`

#### 3. 移动端响应式 📱
- **断点**：768px / 480px
- **优化**：
  - 隐藏次要列（份额、成本、天数）
  - 增大触摸目标到 44px
  - 固定底部导航栏
  - 优化字体和间距

#### 4. 定投计划管理 💰
- **位置**：交易页下方
- **功能**：
  - 创建/编辑/删除定投计划
  - 支持周投/双周/月投三种频率
  - 自动计算下次执行日期
  - 启用/暂停计划
  - 标记已执行
- **API**：
  - `GET/POST /api/sip`
  - `GET/PATCH/DELETE /api/sip/{plan_id}`
  - `POST /api/sip/{plan_id}/execute`
