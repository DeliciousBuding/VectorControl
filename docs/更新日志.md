## 2026-02-11 - 性能优化与故障修复

### 故障修复

#### 1. 生产环境 502 Bad Gateway 修复
- **问题**：用户登录 POST `/api/auth/login` 返回 502 Bad Gateway
- **根因**：Nginx 容器无法解析 Docker 内部主机名 `backend`（DNS 解析失败 NXDOMAIN）
- **修复**：在 Nginx `location /api/` 块中添加 `resolver 127.0.0.11;`，执行 `nginx -s reload`
- **影响文件**：`deploy/nginx/site.conf`

### 性能优化

#### 2. Nginx 静态资源缓存优化
- **优化项**：
  - `/assets/` 目录下的 hashed 静态资源添加 `Cache-Control: public, max-age=31536000, immutable`
  - HTML 文件改用 `no-cache`（替代 `no-store`），启用 bfcache
  - favicon 等非 hashed 资源设置 `max-age=86400`（1天）
- **影响文件**：`deploy/nginx/site.conf`

#### 3. 字体加载优化
- **优化项**：移除 Google Fonts `@import`（Manrope 和 Noto Sans SC）
- **改用**：系统字体栈 `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, 'Noto Sans SC', sans-serif`
- **收益**：节省 456KB 网络流量（占原总流量的 64%）
- **影响文件**：`frontend/src/index.css`

#### 4. 骨架屏和资源预加载
- **优化项**：
  - 在 `index.html` 的 `<div id="root">` 中添加骨架屏 HTML（模拟登录页面布局）
  - 添加内联关键 CSS 骨架屏样式（CSS 动画模拟加载效果）
  - 添加 `<link rel="modulepreload">` 预加载入口 JS
- **影响文件**：`frontend/index.html`

## 2026-02-09 - mot-bot 开发马拉松

### 新增功能

#### 1. 收益曲线图 📊
- **位置**：首页 SummaryCards 下方
- **功能**：
  - 支持 7天/30天/90天/全部 四个时间范围切换
  - 显示累计收益率曲线
  - 0% 基准线
- **技术**：Chart.js + react-chartjs-2
- **API**：`/api/charts/cumulative_returns`

#### 2. 基准对比 📈
- **位置**：首页收益曲线下方
- **功能**：
  - 对比沪深300、中证500、创业板50
  - 显示超额收益
  - 标记跑赢/跑输状态
  - 高亮最接近的基准
- **API**：`/api/benchmark/comparison`

#### 3. 移动端响应式 📱
- **断点**：768px / 480px
- **优化**：
  - 隐藏次要列（份额、成本、天数）
  - 增大触摸目标到 44px
  - 固定底部导航栏
  - 优化字体和间距

#### 4. 定投计划管理 💰
- **位置**：交易页下方
- **功能**：
  - 创建/编辑/删除定投计划
  - 支持周投/双周/月投三种频率
