# 产品需求与页面蓝图（VectorControl）

> 本文档按“页面-组件-字段-交互-验收”组织，直接用于拆任务与验收。

## 1. 阶段二目标
1. 多用户登录与数据隔离可用且可验证。
2. 持仓页成为主工作台，首页聚焦“任务与状态”。
3. 交易链路可达且低摩擦（买入/定投/赎回/转换）。
4. 数据口径一致，异常可降级，页面不崩溃。

## 1.1 当前实施状态（2026-02）
- 已落地：底部 5 Tab、首页“资产总览 + 主CTA + 今日待办”最小版。
- 已落地：持仓主表与基金详情增强。
- 已落地：全局搜索联想（对接 `/api/funds/suggest`，支持代码/名称/拼音）。
- 已落地：消息中心与交易记录最小可用版本（近7天记录）。
- 已落地：首屏性能最小集（骨架屏、5秒超时降级提示、本地埋点）。

## 2. 登录态与数据隔离（P0必须）
### 2.1 登录态定义
- 认证：Bearer Session Token。
- 会话策略：默认可多设备并行，过期后必须重新登录。
- 退出登录：清理 token、用户缓存、搜索历史、草稿状态。

### 2.2 隔离边界
- 数据层隔离：持仓、动作、快照、设置、自选、提醒规则均按 `user_id`。
- 本地缓存隔离：缓存键必须包含 `user_id` 前缀。
- 切账号行为：切换后先清 UI 旧数据，再拉新账号数据。

### 2.3 隔离验收
1. A 账号创建自选/定投，退出后 B 登录不可见且不闪现。
2. 切账号时页面只显示 skeleton，不显示上个账号旧值。
3. 断网重启后不会恢复其他账号缓存数据。

## 3. 页面蓝图
### 3.1 首页（任务流）
- 模块顺序：搜索与消息 -> 资产总览 -> 主CTA -> 今日待办 -> 自定义模块区。
- 组件：`TopSearchBar`、`AssetKpiCard`、`PrimaryCtaButton`、`TodayTodoCard`、`HomeModuleGrid`。
- 首屏可测验收：
1. 3 秒内渲染首屏骨架（资产/CTA/待办）。
2. 5 秒内资产总览完成一次有效更新。
3. 超时显示“数据不完整+查看原因”入口。

### 3.2 自选
- 分组：观察、定投池（P0），核心池（P1）。
- 组件：`WatchlistGroupTabs`、`WatchlistTable`、`BatchActionBar`。
- 每行字段：名称、代码、今日涨跌、近30日、最大回撤、距新高。
- 验收：批量提醒设置不超过 2 步。

### 3.3 交易
- 子页：买入、定投、赎回、转换。
- 组件：`TradeForm`、`AmountChips`、`FeeAndConfirmPanel`、`TradeResultCard`。
- P0 最小闭环：四类交易入口可直接提交到 `/api/actions`，提交后显示结果卡并回显到交易记录。
- P1 当前增量：支持“定投多计划”最小管理（新增、暂停/恢复），并可记录“扣款失败/补扣完成”；首页“今日待办”联动展示失败计划数量并直达交易页处理。
- 验收：详情到下单成功不超过 3 次点击。

### 3.4 持仓（核心）
- 模块：总览 -> 今日贡献Top3 -> 持仓列表 -> 风险卡（底部）。
- 每行字段：基金名、占比、持有收益、当日收益、波形图。
- 列表行为：排序、编辑、归档、快速动作。
- 市场分组判定优先级：
1. 资产类别
2. 市场（CN/HK/US/Global）
3. 币种（CNY/HKD/USD）
- QDII 规则：按底层市场/币种归为“海外”，标签保留 `QDII`。

### 3.5 基金详情
- 第一屏：名称代码风险、净值/估值、关键区间收益、主图、操作栏。
- 图表分层策略：
- `P0`：基金线 + 成本虚线 + 0%基准线。
- `P1`：对标指数线 + 我的收益线（可开关）。
- 周期：1M/3M/6M/1Y/3Y。
- Tooltip：显示当前时间点所有可用线数值。
- 验收：图表口径与列表小波形一致。

### 3.6 消息中心（P1）
- 分类：交易、提醒、系统。
- 每条消息带动作按钮（补扣/去设置/去详情）。
- 验收：扣款失败消息 2 步内可完成补扣。

### 3.6.1 提醒规则中心（P1最小可用）
- 入口：`我的`页内嵌规则中心，不新增独立路由。
- 规则字段：规则名、基金代码（可选）、比较符（`<=` / `>=`）、阈值、静默期（小时）。
- 规则动作：新增、暂停/启用。
- 触发说明：展示“当前值 vs 阈值”与规则文本，解释触发原因。
- 验收：新增规则后刷新仍可回显；规则暂停后不再标记“已触发”。

### 3.7 交易记录（P1）
- 列表：最近 30 天买入/赎回/转换/定投扣款/失败。
- 订单状态：处理中、已确认、失败（带失败原因）。
- 验收：从交易结果页可一键到订单详情。

### 3.8 我的与设置
- 模块：账号资料、通知设置、显示偏好、会话安全。
- 预留：飞书、邮件配置（先配置不发送）。
- 验收：配置保存后刷新可回显。

## 4. 字段与状态口径
### 4.1 显示口径
- 持有收益：金额 + 收益率双行右对齐。
- 最新净值：涨跌幅 + 净值双行右对齐。
- 标题日期化：`当日收益(02-06)`、`持有收益(02-06)`。

### 4.2 时间口径字段
- `as_of`：数据对应时间（交易日/时间点）。
- `updated_at`：系统拉取更新时间。
- `confirm_state`：`estimated` / `confirmed` / `partial`。
- `coverage`：`total/ok/failed`。
- UI 标签统一映射：
  - `estimated` -> `估算中`
  - `confirmed` -> `已更新`
  - `partial` -> `数据不完整`

### 4.3 收益算法口径（统一）
- 当日收益：使用估值口径（收盘确认后可切换为确认值）。
- 持有收益：当前市值 - 成本基准。
- 成本线：采用加权成本口径。

## 5. 边界与异常
- 未登录访问业务接口返回 401，前端跳登录页。
- 外部源部分失败显示覆盖率与失败原因，不阻断全页。
- 归档持仓默认隐藏，`include_archived=true` 才显示。
- 颜色不是唯一信息源：同时显示 `+/-` 与方向符号。

## 6. 空状态与引导
- 首页空持仓：主CTA“去买第一只”。
- 持仓空：引导“导入持仓”或“去交易”。
- 自选空：引导“去搜索并加入自选”。

## 7. Gate 验收定义（必须可执行）
### Gate-A（登录与隔离）
1. 登录、退出、切账号流程正确。
2. 缓存隔离不串号。
3. 未登录访问业务接口统一 401。

### Gate-B（主路径可用）
1. 首页 -> 持仓 -> 详情 -> 买入/定投 -> 结果页可达。
2. 交易结果页可跳交易记录。
3. 消息待办可闭环到操作页面。

### Gate-C（数据一致性）
1. KPI、列表、详情图口径一致。
2. 覆盖率与失败原因可见。
3. 外部源失败时页面不中断。

## 8. 总控执行顺序
1. 先通过 Gate-A/B/C 的基础回归。
2. 先后端隔离与接口，再前端任务流改造。
3. 先首页/持仓主路径，再交易与消息。
4. 每完成一个模块即更新 `ROADMAP.md`。
