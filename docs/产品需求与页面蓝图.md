# 产品需求与页面蓝图（VectorControl）

> 本文档用于总控单人推进阶段二，按“页面-组件-字段-交互-验收”组织。

## 1. 产品目标（阶段二）
1. 多用户登录与数据隔离可用。
2. 持仓页成为主工作台（高频入口）。
3. 交易链路可达且低摩擦（买入/定投/赎回/转换）。
4. 首页从资讯流转为任务流。

## 2. 页面蓝图

### 2.1 首页
- 模块顺序：搜索与消息 -> 资产总览 -> 主CTA -> 今日待办 -> 自定义模块区
- 组件：`TopSearchBar`、`AssetKpiCard`、`PrimaryCtaButton`、`TodayTodoCard`、`HomeModuleGrid`
- 关键字段：总资产、今日收益、持有收益、可用资金、近7日趋势
- 验收：首屏 10 秒内完成状态读取

### 2.2 自选
- 分组：观察/定投池（P0），核心池（P1）
- 组件：`WatchlistGroupTabs`、`WatchlistTable`、`BatchActionBar`
- 每行字段：名称、代码、今日涨跌、近30日、最大回撤、距新高
- 验收：批量提醒设置不超过 2 步

### 2.3 交易
- 子页：买入、定投、赎回、转换
- 组件：`TradeForm`、`AmountChips`、`FeeAndConfirmPanel`、`TradeResultCard`
- 验收：详情到下单成功不超过 3 次点击

### 2.4 持仓（核心）
- 模块：总览 -> 今日贡献Top3 -> 持仓列表 -> 风险卡（底部）
- 每行字段：基金名、占比、持有收益、当日收益、波形图
- 列表行为：排序、编辑、归档、快速动作
- 验收：国内/港股在上，美股/海外在下，排序稳定

### 2.5 基金详情
- 第一屏：名称代码风险、净值/估值、关键区间收益、主图、操作栏
- 图表：当日图 + 业绩图（1M/3M/6M/1Y/3Y）
- 叠加线：基金线、对标指数线、我的收益线、成本虚线
- 验收：图表口径与列表小波形一致

### 2.6 我的与设置
- 模块：账号资料、通知设置、显示偏好、会话安全
- 预留：飞书机器人、邮件推送配置（先配置不发送）
- 验收：配置保存后刷新可回显

## 3. 字段与状态口径
- 持有收益：金额 + 收益率双行
- 最新净值：涨跌幅 + 净值双行
- 当日收益/持有收益标题附日期，如 `当日收益(02-06)`
- 状态标签：`估算中`、`已更新`、`数据不完整`

## 4. 边界与异常
- 未登录访问业务接口返回 401，并跳转登录页
- 外部源部分失败时显示覆盖率与失败原因，不阻断全页
- 归档后默认列表不显示，开启“包含归档”可查看

## 5. 阶段二总控执行顺序
1. 先稳后快：Gate-A/B/C 文档与回归先通过。
2. 先后端隔离与持仓接口，再前端任务流改造。
3. 先首页/持仓主路径，再做交易细节和消息中心。
4. 每完成一个模块即更新 ROADMAP 状态。
