# 状态解释验收样例（data_status + /system/status）

更新时间：2026-02-07

用途：作为发布前与 Gate-D 验收的“状态解释”固定基线，确保系统能明确回答“当前数据口径是什么、时点是什么、为何是这个状态”。

---

## 1. 验收目标

- 所有核心页面都能展示并解释 `data_status`。
- 核心接口返回结构一致：`status/asof/note`。
- `/api/system/status` 可用于追踪版本、快照与任务状态。

---

## 2. 标准字段定义

```json
{
  "status": "confirmed | estimating | partial",
  "asof": "2026-02-07T15:00:00+08:00",
  "note": "可读说明（例如：含 1 笔 pending 交易）"
}
```

- `confirmed`：口径已确认，可作为结算/复盘口径。
- `estimating`：含估算值，收盘后可能回补。
- `partial`：存在缺口或混合口径，需要人工复核。

---

## 3. 接口验收样例

> 说明：以下样例用于验收格式与语义，不要求数值完全一致。

### 3.1 `GET /api/estimate`

验收点：
- 顶层包含 `data_status`。
- `data_status.status` 与覆盖率、失败项说明语义一致。

样例（`estimating`）：

```json
{
  "asof": "2026-02-07T14:58:00+08:00",
  "coverage": { "total": 9, "ok": 8, "failed": 1 },
  "data_status": {
    "status": "estimating",
    "asof": "2026-02-07T14:58:00+08:00",
    "note": "含估算值，1 只基金待确认"
  }
}
```

### 3.2 `GET /api/transactions?status=all`

验收点：
- 顶层包含 `summary` 与 `data_status`。
- `pending_count > 0` 时，`status` 不能是 `confirmed`。

样例（`partial`）：

```json
{
  "summary": {
    "total_count": 12,
    "pending_count": 2,
    "confirmed_count": 10,
    "last_occurred_at": "2026-02-07T09:33:00+08:00"
  },
  "data_status": {
    "status": "partial",
    "asof": "2026-02-07T09:33:00+08:00",
    "note": "当前含 2 笔 pending / 10 笔 confirmed 交易"
  }
}
```

### 3.3 `POST /api/transactions/sync_pending`

验收点：
- 对账结果包含 `result`。
- 返回新的 `data_status`，能解释对账后状态。

样例（`confirmed`）：

```json
{
  "result": {
    "total_pending": 2,
    "synced": 2,
    "skipped": 0,
    "errors": 0
  },
  "data_status": {
    "status": "confirmed",
    "asof": "2026-02-07T15:05:00+08:00",
    "note": "交易流水均已确认"
  }
}
```

### 3.4 `GET /api/system/status`

验收点：
- 返回 `version`、`commit`、`server_time`。
- `snapshot` 下存在 `estimate_snapshot`、`fund_nav_daily`、`transactions_sync_pending`。

样例（节选）：

```json
{
  "service": "vectorcontrol-backend",
  "version": "v1.0.4",
  "commit": "a056746",
  "server_time": "2026-02-07T15:08:00+08:00",
  "snapshot": {
    "estimate_snapshot": { "available": true, "asof": "2026-02-07T14:58:00+08:00" },
    "fund_nav_daily": { "record_count": 4800 },
    "transactions_sync_pending": { "available": true, "last_run_at": "2026-02-07T15:05:00+08:00" }
  }
}
```

## 4. 页面验收清单（手工）

### 4.1 首页/持仓/交易/基金中心口径条

- [ ] 页面显示状态：`已确认/估算中/部分可用`。
- [ ] 显示时点 `asof`。
- [ ] 显示可读说明 `note`。

### 4.2 持仓页基金详情图表区

- [ ] 三个图表区均显示动态口径提示（非静态文案）。
- [ ] 切换基金后，图表区口径随 `confirm_state/asof` 更新。

### 4.3 交易页

- [ ] `pending/confirmed` 数量与 `summary` 一致。
- [ ] 执行 `sync_pending` 后，结果卡与 `data_status` 同步变化。

### 4.4 系统状态页（`/system/status`）

- [ ] 可看到 `version/commit/server_time`。
- [ ] 可看到快照摘要与最近任务状态。

---

## 5. 验收命令参考

```bash
curl -s https://<domain>/api/estimate
curl -s https://<domain>/api/transactions?status=all
curl -s -X POST https://<domain>/api/transactions/sync_pending -H "Content-Type: application/json" -d "{\"limit\":200}"
curl -s https://<domain>/api/system/status
```
