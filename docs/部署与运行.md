# 部署与运行（VectorControl）

## 1. 本地开发环境

### 1.1 环境要求
- Python 3.11+
- Node.js 18+
- npm 9+

### 1.2 本地启动
后端：
```bash
cd backend
pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 21345
```

前端：
```bash
cd frontend
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

访问地址：
- 前端：`http://127.0.0.1:5173`
- 健康：`http://127.0.0.1:21345/api/health`

### 1.3 Windows 快捷脚本
- `scripts/start_backend.bat`
- `scripts/start_frontend.bat`

建议顺序：先后端，再前端。

## 3. VPS 生产部署（Gate-D）

> 方案：`Nginx + Docker Compose + Let's Encrypt`  
> 生产只暴露 `80/443`，后端与数据库不对公网映射端口。

### 3.1 前置条件
- Ubuntu 22.04+（其他 Linux 也可）
- 已安装 Docker 与 Docker Compose
- 已完成域名解析（A 记录指向 VPS）
- 开放安全组/防火墙：`80/443`

### 3.2 首次部署（3 条命令）
```bash
cp deploy/.env.example deploy/.env.prod
vim deploy/.env.prod
bash scripts/deploy_prod.sh
```

`deploy/.env.prod` 至少配置：
- `VC_DOMAIN=你的域名`
- `VC_EMAIL=证书邮箱`
- `API_TOKEN=强随机值`

### 3.3 部署验收（Gate-D）
```bash
VC_DOMAIN=你的域名 python3 scripts/check_gate_d.py
```

通过标准：
1. `https://<domain>/` 可访问，且含 VectorControl 标识。
2. `https://<domain>/api/healthz` 返回 200。
3. 未登录访问 `https://<domain>/api/auth/me` 返回 401。
4. `nginx/backend/postgres` 容器均为 running。

### 3.4 日常更新
```bash
bash scripts/update_prod.sh
```

### 3.5 数据备份
```bash
bash scripts/backup_db.sh
```

默认备份：
- 源：`deploy/data/backend/app.db`
- 目标：`deploy/backups/app-时间戳.db.gz`
- 保留：14 天（可通过 `RETENTION_DAYS` 覆盖）

### 3.6 证书续期
```bash
bash scripts/renew_cert.sh
```

可配置 cron（示例，每天 03:20）：
```bash
20 3 * * * cd /path/to/VectorControl && bash scripts/renew_cert.sh >> /var/log/vectorcontrol-renew.log 2>&1
```

## 4. 回滚方案
1. 切回目标提交：
```bash
git checkout <commit_or_tag>
```
2. 重启生产容器：
```bash
docker compose --env-file deploy/.env.prod -f deploy/docker-compose.prod.yml up -d --build
```
3. 再次执行 Gate-D：
```bash
VC_DOMAIN=你的域名 python3 scripts/check_gate_d.py
```

## 5. 安全说明
- 仅 Nginx 暴露 `80/443`。
- 后端与数据库只在 Docker 内部网络通信。
- 不要提交 `deploy/.env.prod`、`deploy/certbot/`、`deploy/data/`、`deploy/backups/`。
- 建议定期轮换 `API_TOKEN` 与数据库密码。

## 6. 常见问题

### 6.1 `docker: command not found`
未安装 Docker，先安装 Docker Engine 与 Compose 插件。

### 6.2 证书签发失败
- 检查域名解析是否指向当前 VPS
- 检查 80 端口是否被占用或被防火墙拦截
- 确认邮箱与域名填写正确

### 6.3 前端页面 404 或空白
- 确认 `frontend-build` 执行成功
- 确认 `deploy/data/frontend-dist` 有 `index.html`
- 检查 Nginx 配置中 `try_files` 是否生效

### 6.4 中文乱码（PowerShell）
```powershell
chcp 65001
```
