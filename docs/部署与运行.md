# 部署与运行手册

本文档承接 README 中的部署与操作细节，覆盖本机运行、Docker 运行、接口验证和常见排错。

## 1. 环境要求

- Python 3.11+
- Node.js 18+
- npm 9+
- Windows / Linux / macOS（本文命令优先给出 Windows 与通用 Shell）

## 2. 环境变量

根目录可使用 `.env`：

- `API_TOKEN`：接口访问令牌
- `PORT`：后端端口（默认 `21345`）
- `TZ`：时区（默认 `Asia/Shanghai`）

如果未设置 `API_TOKEN`，后端启动时会生成运行时令牌，写入：

- `backend/data/runtime_token.txt`

## 3. 本机启动（手工命令）

### 3.1 启动后端

```bash
cd backend
pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 21345
```

### 3.2 启动前端

```bash
cd frontend
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

### 3.3 访问地址

- 前端：`http://127.0.0.1:5173`
- 后端健康检查：`http://127.0.0.1:21345/api/health`

## 4. Windows 一键启动

仓库提供批处理脚本：

- `scripts/start_backend.bat`
- `scripts/start_frontend.bat`

建议先启动后端，再启动前端。

## 5. Docker 启动

```bash
docker compose -f docker/docker-compose.yml up --build
```

## 6. 最小验收清单

### 6.1 基础健康检查

```bash
curl http://127.0.0.1:21345/api/health
```

预期：返回 `ok=true`。

### 6.2 获取 token（如使用运行时 token）

```bash
cat backend/data/runtime_token.txt
```

### 6.3 鉴权接口检查

```bash
curl -H "Authorization: Bearer <API_TOKEN>" http://127.0.0.1:21345/api/config
curl -H "Authorization: Bearer <API_TOKEN>" http://127.0.0.1:21345/api/estimate
curl -H "Authorization: Bearer <API_TOKEN>" http://127.0.0.1:21345/api/risk/overview
```

预期：返回 200 且结构化 JSON。

## 7. 常见问题排错

### 7.1 前端 5173 打不开

- 检查前端进程是否启动。
- 检查端口占用：

```powershell
Get-NetTCPConnection -LocalPort 5173
```

### 7.2 后端 21345 无响应

- 检查后端日志输出是否报错。
- 检查端口占用：

```powershell
Get-NetTCPConnection -LocalPort 21345
```

### 7.3 Node/npm 无法识别

- 重新打开终端或刷新 `PATH`。
- 检查版本：

```bash
node -v
npm -v
```

### 7.4 控制台中文乱码

Windows PowerShell 执行：

```powershell
chcp 65001
```
