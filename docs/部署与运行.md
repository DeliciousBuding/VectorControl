# 部署与运行（VectorControl）

## 1. 环境要求
- Python 3.11+
- Node.js 18+
- npm 9+
- Windows / Linux / macOS

## 2. 环境变量
根目录可配置 `.env`：
- `API_TOKEN`：接口鉴权 token
- `PORT`：后端端口（默认 `21345`）
- `TZ`：时区（默认 `Asia/Shanghai`）

未设置 `API_TOKEN` 时，后端会在启动后生成运行时 token：
- `backend/data/runtime_token.txt`

## 3. 本机快速启动
### 3.1 启动后端
```bash
cd backend
pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 21345
```

### 3.2 启动前端
```bash
cd frontend
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

### 3.3 访问地址
- 前端：`http://127.0.0.1:5173`
- 健康检查：`http://127.0.0.1:21345/api/health`

## 4. Windows 脚本启动
- `scripts/start_backend.bat`
- `scripts/start_frontend.bat`

建议顺序：先后端，再前端。

## 5. Gate-A：5分钟可复现验收清单
1. 后端 `/api/health` 返回 200。
2. 前端页面可打开并输入 token。
3. 点击刷新后可看到估值与持仓数据（首页与持仓页）。
4. 动作勾选可写入 `/api/actions`。
5. `/api/report/daily` 返回结构化内容。
6. 底部 5 Tab 可切换（首页/自选/交易/持仓/我的）。

## 6. 接口烟测命令
```bash
curl http://127.0.0.1:21345/api/health

curl -H "Authorization: Bearer <API_TOKEN>" http://127.0.0.1:21345/api/estimate

curl -H "Authorization: Bearer <API_TOKEN>" http://127.0.0.1:21345/api/report/daily
```

## 7. Gate-A 自动自测脚本
后端启动后可执行：

```bash
python scripts/check_gate_a.py
```

可选环境变量：
- `VECTORCONTROL_BASE_URL`（默认 `http://127.0.0.1:21345`）

脚本会检查：
1. `/api/health` 可用
2. 未登录访问 `/api/config` 返回 401
3. A/B 用户注册成功
4. 用户A退出后旧 token 失效（401）
5. 用户A重新登录成功
6. A 用户创建持仓后，B 用户不可见（硬隔离）

## 8. Gate-A 一键复现闭环（推荐）
在新机器或新环境中可直接执行：

```bash
python scripts/check_gate_a_full.py
```

脚本会自动：
1. 拉起后端并等待 `/api/health`
2. 拉起前端并验证 `http://127.0.0.1:5173` 可访问
3. 调用 `scripts/check_gate_a.py` 完成登录/切账号/401/隔离验收
4. 自动停止前后端进程

若脚本输出 `Gate-A 新机器复现闭环检查通过`，可视为 Gate-A 达标。

## 9. Gate-B 主路径闭环验收
后端与前端已启动后，可执行：

```bash
python scripts/check_gate_b.py
```

检查项：
1. 首页可访问（5173）
2. 会话注册与 `/api/config` 可用
3. `/api/estimate`、`/api/advice` 返回正常
4. `/api/actions` 写入并可查询
5. `/api/report/daily` 返回结构化结果

一键启动并验收：

```bash
python scripts/check_gate_b_full.py
```

若输出 `Gate-B 主路径闭环检查通过`，可视为 Gate-B 验收用例达标。

## 10. 常见问题
### 8.1 前端打不开 `5173`
- 确认 `npm run dev` 正在运行。
- 检查端口占用。

### 8.2 后端 `21345` 无响应
- 查看后端日志。
- 检查端口占用。

### 8.3 中文乱码
PowerShell 执行：
```powershell
chcp 65001
```

- `scripts/check_gate_b.py` 已包含核心接口字段校验（config/estimate/advice/actions/report）。
- 每次改动接口后，需先更新 `docs/接口契约.md`，再执行 `python scripts/check_gate_b_full.py` 回归，确保契约未破坏。

## 12. Gate-C 降级覆盖率验收
在后端已启动场景下执行：
```bash
python scripts/check_gate_c.py
```
一键拉起后端并验收：
```bash
python scripts/check_gate_c_full.py
```
通过标准：
1. `/api/estimate` 返回 `coverage.total/ok/failed`。
2. 估值部分失败时，失败基金包含 `reason`。
3. 降级后 `/api/advice` 与 `/api/report/daily` 仍可用。

## 13. 首屏性能可测化验收
一键执行首屏性能门禁（含前后端拉起与静态口径校验）：
```bash
python scripts/check_home_perf.py
```
通过标准：
1. 后端健康检查可用，前端首页可访问。
2. 前端存在 `skeletonLock` 骨架状态控制。
3. 前端存在 3 秒骨架定时与 5 秒超时降级定时。
4. 前端存在超时降级状态 `assetTimedOut` 与埋点 `recordMetric`。
