# 部署与运行（VectorControl）

## 1. 环境要求
- Python 3.11+
- Node.js 18+
- npm 9+
- Windows / Linux / macOS

## 2. 环境变量
根目录可配置 `.env`：
- `API_TOKEN`：接口鉴权 token
- `PORT`：后端端口（默认 `21345`）
- `TZ`：时区（默认 `Asia/Shanghai`）

未设置 `API_TOKEN` 时，后端会在启动后生成运行时 token：
- `backend/data/runtime_token.txt`

## 3. 本机快速启动
### 3.1 启动后端
```bash
cd backend
pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 21345
```

### 3.2 启动前端
```bash
cd frontend
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

### 3.3 访问地址
- 前端：`http://127.0.0.1:5173`
- 健康检查：`http://127.0.0.1:21345/api/health`

## 4. Windows 脚本启动
- `scripts/start_backend.bat`
- `scripts/start_frontend.bat`

建议顺序：先后端，再前端。

## 5. Gate-A：5分钟可复现验收清单
1. 后端 `/api/health` 返回 200。
2. 前端页面可打开并输入 token。
3. 点击刷新后可看到估值与持仓数据。
4. 动作勾选可写入 `/api/actions`。
5. `/api/report/daily` 返回结构化内容。

## 6. 接口烟测命令
```bash
curl http://127.0.0.1:21345/api/health
curl -H "Authorization: Bearer <API_TOKEN>" http://127.0.0.1:21345/api/config
curl -H "Authorization: Bearer <API_TOKEN>" http://127.0.0.1:21345/api/estimate
curl -H "Authorization: Bearer <API_TOKEN>" http://127.0.0.1:21345/api/risk/overview
curl -H "Authorization: Bearer <API_TOKEN>" http://127.0.0.1:21345/api/advice
curl -H "Authorization: Bearer <API_TOKEN>" http://127.0.0.1:21345/api/report/daily
```

## 7. 常见问题
### 7.1 前端打不开 `5173`
- 确认 `npm run dev` 正在运行。
- 检查端口占用。

### 7.2 后端 `21345` 无响应
- 查看后端日志。
- 检查端口占用。

### 7.3 中文乱码
PowerShell 执行：
```powershell
chcp 65001
```
