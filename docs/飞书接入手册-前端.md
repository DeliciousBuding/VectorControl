# 飞书接入手册（前端）

更新时间：2026-02-08 19:40:12

## 1. 目标与范围

- 目标：在前端“设置中心”完成飞书通知参数配置，供后端通知通道读取并执行发送。
- 范围：仅涉及前端配置入口、字段约束、联调排障、回滚步骤。
- 非范围：前端不直接发起飞书消息发送请求，不持有飞书 App 凭据，不处理发送重试逻辑。

## 2. 配置入口

- 页面入口：`我的 -> 更多设置 -> 设置中心 -> 飞书机器人（预留）`
- 相关前端文件：
  - `frontend/src/components/SettingsDrawer.jsx`
  - `frontend/src/hooks/usePortfolio.js`
- 配置持久化接口：
  - `GET /api/settings`
  - `PUT /api/settings`

## 3. 字段口径（与契约对齐）

`settings.notifications.feishu` 字段：

- `enabled`：是否启用飞书通道（布尔）
- `webhook_url`：飞书机器人 Webhook 地址（字符串）
- `timeout_seconds`：发送超时秒数（建议 `0.5-30.0`）
- `retry_times`：失败重试次数（建议 `0-5` 整数）
- `template`：消息模板（`title_content_metadata` / `content_only`）

默认值（前端）：

- `enabled=false`
- `webhook_url=''`
- `timeout_seconds=3`
- `retry_times=2`
- `template='title_content_metadata'`

## 4. 权限与安全边界

- 前端职责：
  - 展示和保存用户级配置。
  - 做基本输入约束，避免明显非法值。
- 后端职责：
  - 真正执行通知发送、重试、日志追踪。
  - 校验与裁剪最终配置。
- 安全边界：
  - 前端不写入明文密钥到日志或埋点。
  - 回归截图与排障留档需对 `webhook_url` 脱敏（例如仅保留前后缀）。

## 5. 联调与验收步骤（前端）

1. 打开设置中心，填写飞书配置并保存。
2. 刷新页面后重新进入设置中心，确认字段回显一致。
3. 使用浏览器网络面板确认 `PUT /api/settings` 成功，`GET /api/settings` 可读回。
4. 与后端联调消息发送链路时，优先检查：
   - `enabled=true`
   - `webhook_url` 非空
   - `timeout_seconds/retry_times/template` 在建议范围内

## 6. 常见问题排障

- 保存失败 401：
  - 现象：`PUT /api/settings` 返回 401。
  - 处理：重新登录后再保存。
- 保存失败 422/400：
  - 现象：参数越界或格式不合法。
  - 处理：修正 `timeout_seconds/retry_times/template` 到契约范围。
- 保存成功但未收到飞书消息：
  - 先确认后端已启用通知链路（前端仅配置，不负责发送）。
  - 核对 `webhook_url` 是否可用、机器人权限是否正确。
  - 让后端按 `request_id` / `trace_id` 查发送日志。

## 7. 回滚步骤

当飞书通知导致线上异常时，按最小回滚执行：

1. 前端设置中心将 `enabled` 关闭并保存。
2. 必要时清空 `webhook_url`，恢复默认参数。
3. 回归检查 `PUT /api/settings` 成功，页面无白屏/报错。
4. 在 `agent_comms` 留痕回滚动作与影响范围。
