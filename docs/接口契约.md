# 接口契约（VectorControl）

> 本文档定义当前冻结的核心接口结构。允许新增字段，不允许删除字段或改变语义。

## 1. `/api/estimate`（GET）

### 必须字段
- 顶层：`asof`、`buckets`、`funds`
- `funds[]`：
  - `fund_id`
  - `name`
  - `market_value_cny`
  - `cost_basis_cny`
  - `holding_profit_cny`
  - `holding_profit_rate`
  - `day_profit_cny`
  - `yesterday_profit_cny`
  - `holding_days`
  - `position_weight_pct`
  - `status`
  - `reason`
  - `source`
  - `asof`

### 建议字段
- `coverage.total`
- `coverage.ok`
- `coverage.failed`

## 2. `/api/advice`（GET）
- 顶层：`date`、`actions`
- `actions[]`：`key`、`title`、`type`、`enabled`、`reason`

## 3. `/api/actions`（GET/POST）
- 记录执行状态与时间，支持按日期读取。
- 建议字段：`date`、`action_id`、`executed`、`amount`、`updated_at`

## 4. `/api/report/daily`（GET）
- 必须包含：`summary` + `sections[]`
- `sections[]`：`title` + `lines[]`

## 5. `/api/config`（GET）
- 必须包含：`holdings_count` 与当前用户必要会话摘要。

## 6. `/api/holdings`（GET/POST/PATCH/归档）
- `GET /api/holdings?include_archived=false`：
  - 返回 `holdings` + `count` + `include_archived`。
- `POST /api/holdings`：
  - 至少包含 `fund_id`、`name`、`bucket`。
  - 支持幂等覆盖（同用户同 `fund_id` 视为更新并取消归档）。
- `PATCH /api/holdings/{fund_id}`：
  - 更新允许字段：`name`、`bucket`、`market_group`、`tags`、`market_value_cny`、`cost_basis_cny`、`shares`、`start_date`。
- `POST /api/holdings/{fund_id}/archive`：
  - 逻辑归档，不物理删除。

## 7. 错误返回规范
- 中文错误信息。
- 包含可定位字段（例如 `reason` 或 `detail`）。
- 外部源异常优先降级，不直接全量失败。
