# 设计系统与交互规范（VectorControl）

> 目标：形成可工程化落地的统一视觉语言和交互规则，避免页面风格漂移。

## 1. 设计 Token（P0 必做）

### 1.1 颜色（Light）
- `bg`: `#FFFFFF`
- `surface`: `#F7F8FA`
- `border`: `#E6E8EB`
- `textPrimary`: `#111827`
- `textSecondary`: `#6B7280`
- `textTertiary`: `#9CA3AF`
- `accent`: 1 个主强调色（仅用于 CTA/选中态/关键标签）
- `success/warn/error/info`: 固定语义色，涨跌与风险提示统一映射

### 1.2 字体与字号
- `H1 24/32`：资产总览
- `H2 18/24`：模块标题
- `Body 14/20`：正文
- `Caption 12/16`：说明
- 数字排版：`font-variant-numeric: tabular-nums`

### 1.3 间距与圆角
- Spacing：`4/8/12/16/24/32`
- Radius：卡片 `12`，按钮 `10`，输入框 `8`
- Elevation：最多 2 层阴影

### 1.4 动效
- 过渡时长：`150-220ms`
- 首屏必须有 Skeleton

## 2. 关键交互约束
- 全站文案中文，不出现开发术语。
- 图表必须有基准虚线（0% 或成本线）。
- 涨跌默认红涨绿跌，状态语义一致。
- 金额默认不加货币符号，系统默认口径人民币。

## 3. 导航与信息架构
- 底部固定 5 Tab：`首页/自选/交易/持仓/我的`
- 顶部常驻搜索，支持代码/名称/拼音/缩写联想。
- 首页首屏必须可见：`资产总览 + 主CTA + 今日待办`

## 4. 数据展示规范
- 高密度双行：主值大、次值小、右对齐。
- 持仓列表默认分组：`国内/港股在上，美股/海外在下`。
- 表头排序三态：不排序/升序/降序，视觉清晰可识别。
- 每个关键数据区显示更新时间状态（估算/已更新）。

## 5. 可用性与性能
- 长列表使用虚拟化或分页。
- 输入错误就地提示，不用打断弹窗。
- 空状态必须有主动作。
- 1.2x 字体下关键流程不溢出。

## 6. 埋点指标（可用性验收）
- 搜索转化：搜索 -> 详情 -> 加自选/买入。
- 下单转化：到达买入页 -> 提交成功率 -> 耗时。
- 定投行为：创建率、暂停率、补扣率。
- 首页效率：首屏停留和模块点击分布。

## 7. 验收标准
- 新页面不得引入未定义 Token。
- 关键流程必须包含加载/成功/失败三态。
- 首屏 1 屏内完成“看状态+做动作”。
