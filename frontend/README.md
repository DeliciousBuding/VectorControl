# VectorControl 前端

前端定位：用户日常 2-5 分钟使用的持仓工作台。

## 1. 运行命令
```bash
npm install
npm run dev -- --host 127.0.0.1 --port 5173
npm run build
```

## 2. 当前页面方向
- 导航：首页/自选/交易/持仓/我的（阶段二目标）。
- 首屏：资产总览 + 今日待办 + 主CTA。
- 持仓：高密度主表 + 可编辑排序 + 分组展示。
- 详情：多周期图表 + 对标指数 + 成本线。
- 搜索：已接入 `/api/funds/suggest`，支持代码/名称/拼音联想候选。

## 3. 设计与交互规范
- 统一使用设计 Token（见 `docs/设计系统与交互规范.md`）。
- 文案全部中文，不出现开发术语。
- 图表默认带 0% 或成本虚线。
- 数字字段等宽显示，主次层级清晰。

## 4. API 对接原则
- 仅使用相对路径 `/api/*`。
- token 存储：`localStorage` -> `vectorcontrol_token`。
- 请求自动带 `Authorization: Bearer <token>`。
- 失败状态必须可见且可理解。

## 5. 联调边界
- 不直接读写 YAML。
- 不依赖未在 `docs/接口契约.md` 定义的字段。
- 列表小波形与详情图口径一致。
